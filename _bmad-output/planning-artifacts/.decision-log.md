## DL-001 — Single-User, Fully Private, Locally-Hosted Scope
**Date:** 2026-04-30
**Decision:** The product will run locally on a single user's laptop with no authentication, no cloud backend, and no location tracking or data transmission.
**Driver:** Personal utility use case; single developer resource; simplicity and user privacy as core differentiators.
**Alternatives set aside:** SaaS deployment model, multi-user cloud platform, location analytics.
**Status:** Applied to PRD ✓

---

## DL-002 — Reuse Existing gaz_saver.py as Foundation
**Date:** 2026-04-30
**Decision:** The web product will reuse the battle-tested price-fetching and parsing logic from the existing `gaz_saver.py` CLI (270 LOC at time of writing) rather than rewriting the Régie Essence integration from scratch.
**Driver:** Existing code is proven to work; reduces implementation scope.
**Alternatives set aside:** Complete rewrite; dependency on third-party gas pricing API.
**Status:** Applied to PRD ✓ (Implementation Considerations section)
**⚠️ Open tension as of 2026-06-01:** Architecture review found `gaz_saver.py` is now orphaned (not imported by Flask app) and duplicates logic in `api/pricing.py`. Disposition decision pending (DL-002 may be superseded).

## DL-003 — Spatial Anomaly Detection for Price Quality (Bidirectional)
**Date:** 2026-05-01
**Decision:** System detects and excludes stations priced anomalously below or above their local geographic median. Same threshold (5¢/L) and exemption list apply bidirectionally.
**Driver:** Régie Essence listings can lag hours; bidirectional filtering prevents both inflated savings and inflated cost-differentials.
**Alternatives set aside:** One-directional filtering; manual curation; no filtering.
**Status:** Applied to PRD ✓ (FR38–FR44)

---

## DL-004 — Kill-Switch Disabling of Anomaly Filter
**Date:** 2026-05-01
**Decision:** Anomaly filter can be disabled via `anomaly_filter_enabled` in `stations.yaml` without a code deploy.
**Driver:** Operational flexibility for troubleshooting.
**Status:** Applied to PRD ✓ (FR41)

**Date:** 2026-05-01
**Decision:** Emit a structured log entry for every excluded station (both directions) capturing: name, price, local median, neighbor count, radius, data timestamp.
**Driver:** Observability and filter tuning.

## DL-006 — Most Expensive Station Marker and Worst-Station Benchmark
**Date:** 2026-05-09

## DL-007 — Bidirectional Anomaly Threshold and Exemption Application
**Date:** 2026-05-09
**Decision:** Same threshold and exemption list apply to cheap and expensive outlier detection. Exempted stations pass filtering in both directions.
**Driver:** Consistency; known structural discounters should not be penalized in either direction.
**Status:** Applied to PRD ✓ (FR40, FR44)

## DL-008 — Gemini Conversational Assistant with Natural Language Trip Initiation
**Date:** 2026-05-31
**Decision:** Chat panel for natural-language trip initiation, route modification, and map filtering. Agent extracts parameters, auto-fills form, submits plan — no manual clicking.
**Driver:** UX enhancement; reduces cognitive load for repeat trip patterns.
**Alternatives set aside:** Form-only interface; chat for information retrieval only; in-process Gemini integration.
**Status:** Applied to PRD ✓ (FR48–FR66, J5–J7)

## DL-009 — Google ADK Agent as Separate Service
**Date:** 2026-05-31
**Decision:** Conversational assistant runs as a separate Google ADK service, proxied by Flask `/api/chat` endpoint.
**Driver:** Separation of concerns; independent iteration; aligns with Google ADK deployment pattern.
**Alternatives set aside:** Embedded Gemini in Flask; custom intent parser.
**Status:** Applied to PRD ✓ (FR61–FR66, NFR13)
**⚠️ Open tension as of 2026-06-01:** ADK service URL is hardcoded to localhost. Architecture review flags this as deploy blocker. Environment-driven configuration required before any non-localhost deployment.

## DL-010 — Structured Tool-Based Agent Actions (4 tools)
**Date:** 2026-05-31
**Decision:** ADK agent defines 4 structured tools: `submit_trip`, `add_waypoint`, `filter_stations_by_area`, `clear_filter`. Returns JSON with `action`, `params`, `message`.
**Driver:** Determinism; bounded action set prevents hallucination.
**Alternatives set aside:** Free-form agent responses; implicit action inference.
**Status:** Applied to PRD ✓ (FR64–FR65)
**⚠️ Open tension as of 2026-06-01:** Architecture review found each tool is defined in 3 independent places (ADK stub, backend whitelist, frontend dispatcher). Drift is silent. Single-source contract required.

## DL-016 — gaz_saver.py Deleted (Theme E resolved)
**Date:** 2026-06-01
**Decision:** `gaz_saver.py` is dead code. It is deleted. `api/pricing.py` is the canonical Régie Essence integration point — do not reintroduce the standalone CLI.
**Driver:** Migration already completed in Epic 1; `gaz_saver.py` was not imported by the Flask app and duplicated logic in `api/pricing.py`.
**Alternatives set aside:** Retain as first-class CLI deliverable for self-hosters (extract shared client).
**Status:** Applied to PRD ✓ (Executive Summary updated; Implementation Considerations updated; Technical Success + MVP scope updated; PENDING-A resolved)

## DL-017 — Always Localhost; Theme A Scope Trimmed (PENDING-B resolved)

## DL-020 — Architecture Principles Endorsed; Pricing/Geo Stay Deterministic (PENDING-E resolved)
**Date:** 2026-06-01
**Decision:** Endorsed Winston's architectural recommendation:
1. Mapping and pricing computations stay deterministic synchronous Python functions — not wrapped in ADK agents or microservices.
2. The conversational assistant accesses pricing/routing context via tool calls only (`get_current_trip()`, future: `explain_route_ranking()`, `explain_station_exclusion()`).
3. Agent-callable explanations are a Phase 2 future bet (see DL-018).
**Driver:** Deterministic fast functions gain nothing from LLM wrapping; agent-as-caller pattern keeps concerns separated cleanly.
**Alternatives set aside:** Wrap pricing/geo in ADK agents; agent-callable explanations as near-term scope.
**Status:** Applied to PRD ✓ (Architecture Principles section added; PENDING-E resolved)
